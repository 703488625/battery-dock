电量坞 — 蓝牙 / 2.4G 外设电量托盘工具

启动
  双击「电量坞.lnk」或 dist\BatteryDock.exe。
  程序启动后不弹主窗口，会常驻任务栏右下角。

查看电量
  点开任务栏右下角的 ^（隐藏的图标），找到电量坞的电池图标。
  左键单击图标：打开电量面板。
  右键单击图标：打开菜单（刷新 / 开机启动 / 设置 / 退出）。
  建议把电池图标从 ^ 里拖到任务栏上固定，以后单击即可打开。
  打开面板后，按住顶部的标题区域即可用鼠标拖动面板。
  界面为液态玻璃风格；设置 → 外观 → 主题可切换“跟随系统 / 浅色 / 深色”。

设备卡片
  键盘：打开按键测试，按过的键会标绿，底部显示已测试数量。
        测试窗口会接收当前按下的所有键盘按键，测试时请只操作目标键盘。
  鼠标：打开 DPI 与回报率设置。支持雷蛇 2.4G 鼠标和部分罗技 HID++ 鼠标。
        DPI / 回报率修改立即生效，但不写入板载配置，重启后可能恢复原值。
        部分雷蛇型号不支持 HID 回报率切换，界面会提示。
        侧键映射暂未开放。
  耳机：不打开任何页面。
  手柄 / 其他：打开 Windows 蓝牙设置。
  返回：键盘 / 鼠标窗口左上角的“← 返回电量”会关闭工具并回到电量面板原来的位置。

说明
  - 支持充电状态的设备会显示“充电中 / 已充满”，托盘图标同步变绿。
  - 面板打开时按设定频率刷新；关闭后自动降低到至少 2 分钟一次，最长 10 分钟。
  - 刷新时设备卡片原地更新，不会先清空列表；键盘、鼠标、手柄休眠后保留上次电量。
  - 设置里可开启免打扰时段；时段内不弹低电量通知，结束后会补发。
  - 正在充电的设备不会重复弹低电量提醒。
  - 蓝牙和 2.4G 设备会一起显示，状态栏会标出连接方式。
  - 2.4G 雷蛇鼠标休眠时，面板会提示“移动鼠标后读取电量”；动一下鼠标即可。
  - ATK Z87 优先使用 Evision 0x1A 协议读取（本机实测 79%）；休眠时会保留上次电量，按一下按键再刷新。
  - ATK V75X 和部分 ATK / VXE 鼠标使用 COMPX、HECHI 或 Nordic 协议；未适配的型号仍可能需要厂商软件。
  - 罗技无线设备通过 HID++ 2.0 读取，支持 Unifying / Lightspeed / Bolt 接收器；无需安装 G HUB 或 Options+。
  - 罗技 G PRO X SUPERLIGHT（接收器 046D:C547）已实测可用；它的内部名称是“PRO X Wireless”，现在会显示为“G PRO X SUPERLIGHT”并按鼠标处理。
  - 罗技设备优先用序列号或 unit ID 作为身份；换 USB 口、换接收器槽位后仍能沿用上次电量。
  - 接收器会监听设备到达/离开通知；鼠标开关机或接收器插拔后会自动刷新，不用等定时轮询。
  - 罗技设备只上报档位或电压时，百分比是推算值，会显示“≈”；直报百分比时不加“≈”。
  - 华硕 ROG Omni 接收器（0B05:1ACE）已接入鼠标电量协议；本机无 ROG 设备，未实机验证。
  - MCHOSE L7 / M7 / A7 / K7 等 2.4G 鼠标（0x5253 / 0x3837）已接入电量协议；G3 系列不支持；本机无 MCHOSE 鼠标，未实机验证。
  - 其他厂商的私有 2.4G 协议目前可能无法读取，这是协议差异，不是接收器故障。
  - 所有数据只在本机，不联网。

卸载
  右键托盘图标 → 退出；在设置里关闭“开机自动启动”；
  删除 BatteryDock.exe 和本文件夹即可。
