## 已知问题

1. **ATK legacy 0xFF**：Evision 查询失败后，旧 `04 87` 回包可能返回 `0xFF`，当前按 255 缩放到 100%。如果键盘实际未满电，请唤醒后重新读取；不要把它当作精确值。
2. **罗技稳定 ID / 热插拔未最终复测**：代码路径已实现，但最后一次构建验证时 `VID_046D` 接收器不在系统设备列表。重新插回后应检查 `app.log` 中的 `罗技接收器监听`、`罗技接收器通知`、`罗技身份`。
3. **部分设备无法读取**：2.4G 私有协议因型号/固件而异；蓝牙设备也可能不提供电量服务。
4. **Xbox 电量精度**：XInput 只有空 / 低 / 中 / 满 4 档，界面显示 `≈10/40/70/100%`，不是精确百分比；USB 有线只显示“有线”。XInput 也无法区分槽位归属，蓝牙 + 适配器混合场景依赖 `K - N` 去重。
5. **PS 手柄精度**：DualShock 4 / DualSense 只有 0–10 档，界面按档位中值 `≈` 显示，无法提供真正的 1% 精度；异常状态显示原因或上次电量，不会转成 0%。
6. **GameSir 蓝牙模式**：PID `02E0` 不开放电量查询，界面显示原因；Nova 2/T4N2 走 `0xFF7A` 报文，G7 Pro 走 `0xFFF0` 心跳 + `0x12` 状态流。
7. **BETOP 型号差异**：鲲鹏20 的 report id / 偏移不一定适用于其他北通型号，需要实机抓包确认。
8. **SmartScreen**：未签名 exe 首次运行会提示。
