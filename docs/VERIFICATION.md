## 已知问题

1. **ATK legacy 0xFF**：Evision 查询失败后，旧 `04 87` 回包可能返回 `0xFF`，当前按 255 缩放到 100%。如果键盘实际未满电，请唤醒后重新读取；不要把它当作精确值。
2. **罗技稳定 ID / 热插拔未最终复测**：代码路径已实现，但最后一次构建验证时 `VID_046D` 接收器不在系统设备列表。重新插回后应检查 `app.log` 中的 `罗技接收器监听`、`罗技接收器通知`、`罗技身份`。
3. **部分设备无法读取**：2.4G 私有协议因型号/固件而异；蓝牙设备也可能不提供电量服务。
4. **SmartScreen**：未签名 exe 首次运行会提示。
